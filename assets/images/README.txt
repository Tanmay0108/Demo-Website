====================================================================
WEDDING INVITATION — ASSETS & IMAGES DIRECTORY
====================================================================

Drop your wedding photos into this folder using the filenames below:

1. cover.jpg
   - Used for: The opening screen invitation cover (peacock / palace garden / welcome background)
   - Ideal dimensions: 1080 x 1920 px (9:16 vertical / portrait)

2. hero.jpg
   - Used for: The main couple portrait on the first section of the website
   - Ideal dimensions: 1080 x 1920 px (9:16 vertical / portrait)

3. mehndi.jpg
   - Used for: Mehndi ceremony card
   - Ideal dimensions: 800 x 1200 px (3:4 or vertical)

4. haldi.jpg
   - Used for: Haldi ceremony card
   - Ideal dimensions: 800 x 1200 px (3:4 or vertical)

5. sangeet.jpg
   - Used for: Sangeet ceremony card
   - Ideal dimensions: 800 x 1200 px (3:4 or vertical)

6. wedding.jpg
   - Used for: Main wedding ceremony card
   - Ideal dimensions: 800 x 1200 px (3:4 or vertical)

7. reception.jpg
   - Used for: Reception ceremony card
   - Ideal dimensions: 800 x 1200 px (3:4 or vertical)

8. venue.jpg
   - Used for: Venue photograph (optional)
   - Ideal dimensions: 1080 x 720 px or 800 x 800 px

9. social-preview.jpg
   - Used for: Link thumbnail when you send the website link on WhatsApp or Instagram
   - Ideal dimensions: 1200 x 630 px (horizontal 1.91:1)

FORMATS SUPPORTED:
- .jpg, .jpeg, .png, .webp

NOTE:
If you want to use different filenames (e.g. "my-haldi-photo.png"), you can simply
update the image path in `wedding-config.js`!
